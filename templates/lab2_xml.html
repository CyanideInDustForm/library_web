Лабораторная работа №2: XML-файл и JavaScript-таблица

Файл static/xml/handmade.xml создан вручную (не генерируется из базы данных) и содержит 7 элементов <book> по 6 тегов в каждом. Таблица ниже строится прямо в браузере: JavaScript загружает XML через fetch, разбирает его DOMParser'ом и выводит в виде таблицы.

Содержимое handmade.xml
Загрузка XML…
Клик по заголовку колонки сортирует таблицу (повторный клик — в обратном порядке). Числовые колонки («id», «year», «pages») сортируются как числа, остальные — по алфавиту.
