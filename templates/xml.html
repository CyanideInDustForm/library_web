XML-доступ к данным

Все данные библиотеки доступны в формате XML: пять лент формируются из базы данных на лету. Каждая лента оформляется в браузере XSL-таблицей, а её структура описана XSD-схемой. Есть также RSS-лента новостей для подписки.

Как это устроено

  1. Приложение выполняет SQL-запрос к базе данных (SQLite).
  2. Результаты оборачиваются в XML-теги и отдаются с заголовком application/xml.
  3. Инструкция <?xml-stylesheet …?> подключает XSL-таблицу — браузер преобразует XML в читаемую таблицу. Для книг доступны два представления: сортировка по названию и по году издания — и серверная сортировка данных, и xsl:sort в таблице стилей.
  4. Инструкция <?xml-model …?> привязывает XSD-схему — структуру документа можно проверить в XML-редакторе (XMLPad, Oxygen, VS Code).
Такие ленты — готовый формат для обмена данными между приложениями (лабораторная №4 «Организация обмена данными»): любая программа скачивает XML и разбирает его стандартным парсером. XSL-таблицы и сортировка — база для лабораторной №2 (XML/XSL).

Файлы оформления

  • table.xsl — универсальная таблица (новости, выдачи, отзывы)
  • books.xsl и books-year.xsl — каталог с сортировкой
  • events.xsl — афиша с выделением дат
  • news.xsd · books.xsd · loans.xsd · events.xsd · reviews.xsd
